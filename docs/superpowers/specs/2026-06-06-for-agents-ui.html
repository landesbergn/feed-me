Spec · v3.7

For Agents UI

Feed Me · 2026-06-06 · spec

Iterate on the v3.6 For Agents surfaces. The agent prompt moves from a collapsed fold at the bottom of the feed page to a dedicated, personalized page at /u/<secret>/agents, reached by an always-visible card under the episodes. The landing page advertises the capability with a small CSS robot peeking over the "Share any article" step. The prompt copy gets shorter, and copying becomes click-the-box instead of a separate button. No API changes; /AGENTS.md and the agent endpoints are untouched.

1 · Why

v3.6 buried the agent feature in a collapsed "For agents" fold below Settings, where nobody scrolls, and the landing page says nothing about it. The owner wants the capability prominent on the feed page, advertised on the landing page with personality, and the prompt itself leaner (details like the rate cap belong in AGENTS.md, which the agent reads anyway).

2 · What we're building

  1. A step-style card on the feed page (under the episodes section, both page states): 🤖 badge, one line, and a button to the new agents page. Replaces the v3.6 "For agents" fold entirely.
  2. GET /u/{secret}/agents: a small personalized page holding the click-to-copy prompt and a link to /AGENTS.md. New template templates/agents_page.html.
  3. A CSS robot on the landing page peeking over the "Share any article" step with a speech bubble linking to /AGENTS.md.
  4. Copy trims: no cap sentence in the prompt, no privacy line, no "(Claude Code and friends)".

3 · The feed page card

In templates/settings.html, directly after the #episodes-section div (so it is always visible in both the setup-leading and episodes-leading states), a card in the page's existing .step style:

  • The number-circle slot holds 🤖 instead of a digit.
  • Text: "Your agent can share here too".
  • A .btn-secondary link, label "For agents →", href /u/{{ secret }}/agents (relative path, no base needed).

The v3.6 <details class="settings"> "For agents" block, its .agent-prompt CSS, and the copyAgentPrompt() script are removed from settings.html (the prompt now lives on the agents page). The base_url context key stays (harmless, and other templates may use it later); the settings route no longer needs to render the prompt.

4 · The agents page

GET /u/{secret}/agents, route agents_page in app.py:

  • 404 for an unknown feed (match the other /u/{secret} pages).
  • Renders templates/agents_page.html with secret and base_url.
  • Sets the session cookie like the feed page does (it is a human-facing feed page; CLAUDE.md's "set on every feed-page view" convention).
  • Tracks a page_view with path="agents_page".

Page content, in the feed page's visual style (same palette, brand header):

  • Brand line, then h1: "Agents welcome."
  • One sentence: "Give your agent this prompt and it can add articles to your feed:"
  • The prompt box (whole box is the copy control, see below): 
    I have a Feed Me podcast feed. To send an article to it, read
{base}/AGENTS.md and follow it. My feed page: {base}/u/<secret>.
    rendered as one paragraph (no line break), personalized via base_url and secret.
  • A hint line inside the box footer: "⧉ click to copy", which flips to "copied!" for about 1.5 seconds after a successful copy, then reverts. Clipboard failure stays silent (matches copyFeedUrl).
  • Below the box: "The full API, for your agent's eyes:" linking to {base}/AGENTS.md.
  • A back link: "← Back to your feed" to /u/{{ secret }}.
Click-to-copy. No separate Copy button. The box has cursor: pointer, a click handler that writes the prompt text (trimmed, hint excluded) to the clipboard, and role="button" + tabindex="0" + an Enter/Space key handler so it stays keyboard-accessible without a button element.

5 · The landing page robot

In templates/landing.html, the "Share any article" step (step 2) gains a decorative pure-CSS robot peeking over its top edge, per the brainstorm mockup (take 4):

  • Position: the robot's head pokes above the card's top edge, horizontally just past where "Share any article" ends; its lower body hides behind the card (robot z-index below the card, which gets a white background and a stacking context). Two small finger nubs sit on the card edge. The head tilts about −5°.
  • Look: head #8a6f5e (the app's muted brown), rounded top corners; two white eyes with dark pupils; a small white smile; an antenna with a #b04a00 bobble.
  • Bubble: to the robot's right, one line: "or have your AI agent send things". White, 1.5px #E9C9AC border, rounded, with a tail pointing left at the robot's mouth. The bubble is a link to /AGENTS.md (plain ink color, no underline; it is an easter-eggy affordance, not a primary CTA).
  • Spacing: the gap above step 2 grows (~46px instead of 11px) so the robot and bubble have their own air.
  • Accessibility: the robot drawing is aria-hidden="true"; the bubble link's text is the accessible name. Nothing animates.
  • Small screens: positions are tuned in px against the page's 480px max-width column; at narrower widths the bubble may wrap to two lines, which is acceptable ("fix it in post" per the owner).

House rule throughout: no em-dashes in any template or copy.

7 · Testing

  • GET /u/{secret}/agents: 200; body contains the personalized prompt (with https://test.local/u/<secret>), the AGENTS.md link, and the back link; sets the fm_session cookie; unknown secret → 404.

  • Feed page: contains the card ("Your agent can share here too") and the link to /u/{secret}/agents; no longer contains the prompt text or "For agents" fold (update the v3.6 test test_settings_page_shows_for_agents_section accordingly).
  • Landing page: contains "or have your AI agent send things" and an /AGENTS.md link.

  • grep -rn "—" templates/ stays empty.

8 · Out of scope

  • No API changes. /AGENTS.md, /llms.txt, and the episode endpoints are untouched.
  • Robot animation (waving, blinking). Static only.
  • Pixel-perfect responsive tuning of the robot; positions are tuned for the standard column and accepted as-is elsewhere.
  • The unimplemented GA4 spec claims v3.7 in its title; it will renumber when it ships. This release takes v3.7 (it ships first).

9 · Acceptance criteria

  • From the feed page, one tap on "For agents →" lands on /u/<secret>/agents; one click on the prompt box copies the shortened prompt; the hint flips to "copied!".
  • The prompt contains no cap sentence, no privacy line, no "(Claude Code and friends)"; the cap remains documented in AGENTS.md.
  • The landing page shows the robot peeking over step 2 with the bubble "or have your AI agent send things" linking to /AGENTS.md.
  • The old "For agents" fold is gone from the feed page; the new card shows in both page states.
  • All existing tests pass with the v3.6 page-section test updated; CHANGELOG.md gains a v3.7 entry; no em-dashes in templates.
