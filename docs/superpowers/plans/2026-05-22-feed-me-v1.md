# Feed Me v1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the self-serve v1 of Feed Me — a website where anyone can create a private podcast feed of articles they share from iOS, with no account required. Spec: `docs/superpowers/specs/2026-05-21-feed-me-design.html`.

**Architecture:** One Python (FastAPI) process on Fly.io, one volume at `/data` namespaced by per-user secret. Filesystem is the database (`/data/<secret>/{settings.json, <slug>.mp3, <slug>.json}`). Async ingest via `threading.Thread(daemon=True)` spawned per request. URL is the credential (no sessions, no email, no passwords). One canonical iCloud Shortcut authored once, installed by every user, prompts for ingest URL on first run.

**Tech Stack:** Python 3.12, FastAPI, Uvicorn, Jinja2 templates, httpx, readability-lxml, openai SDK, pytest, uv for dependency management, Fly.io for hosting, Docker for the container image.

```
    superpowers/
      specs/2026-05-21-feed-me-design.html
```

Each module has one responsibility:
- `app.py` — HTTP routing and request handling only; delegates to others
- `ingest.py` — the article → MP3 pipeline; stateless functions + module-level clients
- `storage.py` — every disk operation in one place; tested against `tmp_path`
- `rss.py` — pure function: list of episode dicts → XML string

```python
# append to storage.py
def _new_slug() -> str:
    return _secrets.token_urlsafe(12)


def write_episode(
    data_dir: Path, secret: str, *,
    title: str, source_url: str, audio: bytes,
) -> str:
    slug = _new_slug()
    user_dir = data_dir / secret
    (user_dir / f"{slug}.mp3").write_bytes(audio)
    (user_dir / f"{slug}.json").write_text(json.dumps({
        "title": title,
        "url": source_url,
        "ts": int(time.time()),
    }))
    return slug


def write_failed_episode(
    data_dir: Path, secret: str, *,
    source_url: str, error: str,
) -> str:
    slug = _new_slug()
    (data_dir / secret / f"{slug}.json").write_text(json.dumps({
        "title": None,
        "url": source_url,
        "ts": int(time.time()),
        "error": error,
    }))
    return slug
```

```python
# append to storage.py
def list_episodes(data_dir: Path, secret: str) -> list[dict]:
    user_dir = data_dir / secret
    if not user_dir.is_dir():
        return []
    records = []
    for p in user_dir.glob("*.json"):
        if p.name == "settings.json":
            continue
        try:
            data = json.loads(p.read_text())
            data["slug"] = p.stem
            data["mtime"] = p.stat().st_mtime
            data["has_audio"] = (user_dir / f"{p.stem}.mp3").exists()
            records.append(data)
        except (json.JSONDecodeError, OSError):
            continue
    records.sort(key=lambda r: r["mtime"], reverse=True)
    return records
```

```python
# rss.py
from email.utils import format_datetime
from datetime import datetime, timezone
from pathlib import Path

from jinja2 import Environment, FileSystemLoader, select_autoescape

_env = Environment(
    loader=FileSystemLoader(Path(__file__).parent / "templates"),
    autoescape=select_autoescape(["xml"]),
)


def render_feed(*, feed_url: str, audio_base: str, episodes: list[dict]) -> str:
    ready = [e for e in episodes if e.get("has_audio")]
    enriched = [
        {
            **e,
            "pub_date": format_datetime(
                datetime.fromtimestamp(e["ts"], tz=timezone.utc)
            ),
        }
        for e in ready
    ]
    template = _env.get_template("feed.xml")
    return template.render(
        feed_url=feed_url,
        audio_base=audio_base,
        episodes=enriched,
    )
```

```python
import httpx
from readability import Document
from lxml import html as lxml_html

http_client = httpx.Client(
    timeout=30.0,

            "Mozilla/5.0 (Macintosh; Intel Mac OS X 10_15_7) "

def fetch_article(url: str) -> tuple[str, str]:
    resp = http_client.get(url)
    resp.raise_for_status()
    doc = Document(resp.text)
    title = doc.short_title() or doc.title()
    summary_html = doc.summary()
    body = lxml_html.fromstring(summary_html).text_content().strip()
    body = "\n\n".join(line.strip() for line in body.splitlines() if line.strip())
    return title, body
```

```python
import threading
from urllib.parse import urlparse

import ingest


def spawn_ingest(url: str, secret: str, data_dir: Path) -> None:
    t = threading.Thread(
        target=ingest.process,
        args=(url, secret, data_dir),
        daemon=True,

@app.get("/u/{secret}/ingest")
def ingest_route(secret: str, url: str):

        raise HTTPException(404)
    parsed = urlparse(url)
    if parsed.scheme not in ("http", "https") or not parsed.netloc:
        raise HTTPException(400, "invalid url")
    spawn_ingest(url, secret, DATA_DIR)
    return {"ok": True}
```

```python
import re

from fastapi.responses import FileResponse

SLUG_RE = re.compile(r"^[A-Za-z0-9_-]+$")


@app.get("/u/{secret}/audio/{slug}.mp3")
def audio_route(secret: str, slug: str):
```

### Task 26: Author the canonical iOS Shortcut

**Manual on iPhone.**

- [ ] **Step 1: Create the Shortcut**

On your iPhone: Shortcuts app → `+` to create a new shortcut. Name it "Feed Me". Add these actions in order:

1. **If** — `Magic Variable` empty: select "Get Value for Key 'IngestURL' in Variable 'IngestStore'" (you'll need to set up a fake first; see step 2)

Actually the simplest practical recipe that "ask once, remember forever":

1. **Get Variable** → variable name `IngestURL` (Shortcuts persistent variables survive across runs when scoped at the shortcut level via "Set Variable" with no flag)
2. **If** the result of step 1 is empty:
   - **Ask for Input** (URL type), prompt "Paste your ingest URL from feed-me.app"
   - **Set Variable** `IngestURL` to the result
3. **End If**
4. **URL** action — combine `IngestURL` + `?url=` + `Shortcut Input` (the shared URL)
5. **Get Contents of URL** on the previous URL, method `GET`
6. **Show Notification** with the response body (optional)

(Shortcuts' variable persistence is finicky and the exact action names shift between iOS versions; if the above doesn't persist, fall back to writing `IngestURL` to a known Notes note and reading it back. The user-visible behavior is the same: ask once, remember.)
